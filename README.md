EEGo er en React Native- og Expo-app udviklet som støtteværktøj til mennesker med epilepsi.
Appen samler EEG-data, fysiologiske målinger og personlige registreringer i én brugerflade.

Appen forbinder via Bluetooth Low Energy til den tilhørende NeuroKrown-prototype.
Den modtager live EEG-målinger, puls, iltmætning, temperatur og enhedens alarmstatus.
Data præsenteres gennem dashboards, grafer, daglige analyser og historiske oversigter.

Vigtige funktioner:
- Livevisning og analyse af EEG- og sensordata
- Tilstande for Normal, Warning og Alarm
- Anfaldsdagbog med triggere, symptomer og følelser
- Medicinplan, aktiviteter, påmindelser og notifikationer
- Opsætning af nødkontakter og deling med læge
- Valgfri integration med Apple HealthKit

Projektet er en forskningsprototype og ikke et godkendt medicinsk produkt.


--------------------- ENGLISH ---------------------

EEGo is a React Native and Expo application designed to support people with epilepsy.
The app combines EEG data, physiological measurements and personal records in one interface.

It connects to the NeuroKrown prototype through Bluetooth Low Energy.
The app receives live EEG samples, heart rate, oxygen saturation, temperature and device status.
Data is presented through dashboards, charts, daily analyses and historical overviews.

Key features:
- Live EEG and sensor data visualisation
- Normal, Warning and Alarm states
- Seizure diary with triggers, symptoms and emotions
- Medication plans, activities, reminders and notifications
- Emergency-contact and doctor-sharing workflows
- Optional Apple HealthKit integration

This project is a research prototype and is not an approved medical device.
